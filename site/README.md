# SmartLiving Chain · หน้าเว็บระบบสัญญาเช่าบนบล็อกเชน

## โครงสร้างโฟลเดอร์
```
site/
├── index.html        โครงหน้าเว็บ (HTML)
├── css/
│   └── styles.css    ตกแต่งทั้งหมด (CSS)
├── js/
│   └── app.js        ตรรกะการทำงาน เชื่อมกระเป๋า MetaMask และสัญญาบนเชน (JavaScript)
└── assets/           รูปภาพประกอบ (SVG)
```

## วิธีใช้งาน
1. วางทุกไฟล์และโฟลเดอร์ไว้ในโฟลเดอร์เดียวกัน
2. เปิด `index.html` ในเบราว์เซอร์ที่ติดตั้ง MetaMask
3. หน้าเว็บโหลด ethers.js จาก CDN และ Google Fonts จึงต้องต่ออินเทอร์เน็ต

## หมายเหตุ
- ไฟล์ `js/app.js` มีที่อยู่สัญญาและ ABI ฝังอยู่แล้ว
- รูปทรัพย์สินที่อัปโหลดเก็บในเบราว์เซอร์ของเครื่องนั้น ไม่ได้อยู่บนเชน
- `styles.css` รวมการตกแต่งจากหลายรอบไว้ตามลำดับเดิม เพื่อให้หน้าตาเหมือนที่ตรวจแล้ว
